
## Описание данных

Датасет содержит 28 переменных для 239,266 пациентов:

### Демографические переменные
- **Patient_ID**: Уникальный идентификатор пациента
- **Age**: Возраст (числовая)
- **Gender**: Пол (Male/Female)

### Медицинские показатели
- **Hypertension**: Гипертония (Yes/No)
- **Diabetes**: Диабет (Yes/No)
- **Obesity**: Ожирение (Yes/No)
- **Cholesterol_Level**: Уровень холестерина (High/Normal/Low)
- **Blood_Pressure**: Артериальное давление (числовая)
- **Chronic_Kidney_Disease**: Хроническое заболевание почек (Yes/No)
- **Previous_Heart_Attack**: Предыдущий инфаркт (Yes/No)
- **CVD_Risk_Score**: Оценка риска ССЗ (0-100)
- **Heart_Attack**: Инфаркт миокарда - целевая переменная (Yes/No)

### Поведенческие факторы
- **Smoking_Status**: Статус курения (Smoker/Non-Smoker)
- **Alcohol_Consumption**: Употребление алкоголя (Yes/No)
- **Physical_Activity**: Физическая активность (Low/Medium/High)
- **Diet_Score**: Качество питания (Healthy/Moderate/Poor)
- **Stress_Level**: Уровень стресса (Low/Medium/High)

### Социально-экономические факторы
- **Income_Level**: Уровень дохода (Low/Middle/High)
- **Education_Level**: Уровень образования (None/Primary/Secondary/Higher)
- **Employment_Status**: Статус занятости (Employed/Unemployed/Retired)
- **Healthcare_Access**: Доступность медицины (Good/Moderate/Poor)
- **Hospital_Availability**: Доступность больниц (High/Medium/Low)

### Географические переменные
- **Rural_or_Urban**: Тип местности (Rural/Urban)
- **Region**: Регион (Eastern/Western/Northern/Southern/Central)
- **Province**: Провинция (28 провинций Китая)
- **Air_Pollution_Exposure**: Воздействие загрязнения воздуха (Low/Medium/High)

### Другие переменные
- **TCM_Use**: Использование традиционной китайской медицины (Yes/No)
- **Family_History_CVD**: Семейная история ССЗ (Yes/No)

## Методология

### Статистические методы

1. **Описательная статистика**: частоты, проценты, средние значения, стандартные отклонения
2. **Тесты независимости**: хи-квадрат Пирсона, точный тест Фишера
3. **Корреляционный анализ**: корреляция Спирмена, корреляция Кендалла
4. **Дисперсионный анализ**: однофакторный ANOVA, критерий Крускала-Уоллиса
5. **Регрессионный анализ**: множественная линейная регрессия, логистическая регрессия
6. **Анализ выживаемости**: относительный риск (RR), отношение шансов (OR)
7. **Машинное обучение**: Random Forest для оценки важности признаков
8. **Кластерный анализ**: K-Means кластеризация с PCA визуализацией

### Проверка гипотез

#### H1: Распространенность традиционной китайской медицины (TCM)
- **Методы**: хи-квадрат, V Крамера, точный тест Фишера, доверительные интервалы
- **Результат**: Не подтверждается (p = 0.193, V = 0.003)
- **Вывод**: Различия в использовании TCM между сельским и городским населением статистически не значимы

#### H2: Влияние дохода и региона на доступность медицины
- **Методы**: корреляция Спирмена и Кендалла, хи-квадрат, Крускал-Уоллис
- **Результат**: Не подтверждается (ρ = -0.0002, p = 0.903)
- **Вывод**: Уровень дохода и регион не оказывают значимого влияния на доступность медицины

#### H3: Предикторы качества питания
- **Методы**: ANOVA, множественная регрессия, анализ взаимодействий
- **Результат**: Не подтверждается (R² = 0.0001, p > 0.05)
- **Вывод**: Регион, доход и образование не объясняют вариацию качества питания

#### H4: Гипертония и риск инфаркта
- **Методы**: относительный риск, отношение шансов, логистическая регрессия, ROC-анализ
- **Результат**: Не подтверждается (RR = 1.00, p = 0.721)
- **Вывод**: У пациентов с гипертонией инфаркты возникают с той же частотой, что и без гипертонии

#### H5: Накопительный эффект факторов риска
- **Методы**: логистическая регрессия, Random Forest feature importance
- **Результат**: Частично подтверждается (OR = 1.003 на фактор)
- **Вывод**: Топ-3 фактора: курение, наследственность, низкая физическая активность

#### H6: Взаимосвязи переменных образа жизни
- **Методы**: корреляция Спирмена, V Крамера, попарные тесты
- **Результат**: Не подтверждается (все p > 0.05)
- **Вывод**: Стресс, курение, алкоголь и физическая активность не коррелируют между собой

#### H7: Паттерны образа жизни пенсионеров
- **Методы**: описательная статистика, K-Means кластеризация, PCA
- **Результат**: Выявлено 3 кластера пенсионеров
- **Вывод**: Пенсионеры составляют 33.4% выборки, средний возраст 59.4 лет

## Результаты

### Ключевые findings

1. **Отсутствие значимых связей**: Все проверенные гипотезы (H1-H6) не подтвердились на данном датасете
2. **Синтетическая природа данных**: Равномерное распределение категориальных переменных указывает на искусственную генерацию данных
3. **Методологическая валидность**: Использованные статистические методы корректно работают на данных с заложенными закономерностями

### Ограничения исследования

1. **Синтетический датасет**: Данные сгенерированы случайным образом без учета реальных эпидемиологических закономерностей
2. **Отсутствие временной динамики**: Cross-sectional дизайн не позволяет установить причинно-следственные связи
3. **Потенциальные confounders**: Не учтены все возможные смешивающие факторы
